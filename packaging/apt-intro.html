A database of SPI NOR and SPI NAND flash chips (JEDEC ids, part names, sizes, page and sector sizes, erase opcodes, voltages and capabilities), merged from the flash tables in flashrom, flashprog, Linux, U-Boot, Dediprog, Rockchip, OpenOCD, openFPGALoader and QEMU, and the flash chips Zephyr's boards describe. Install python3-spiflash, which also provides the spiflash command (spiflash id ef4018). The package is architecture all (pure Python, no dependencies), so it installs on any Debian or Raspberry Pi OS machine.
